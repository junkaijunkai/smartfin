Job 1: quality-security

Stage 1: Setup & Install ubuntu-latest / Python 3.11

Checkout

Clone repository source code

actions/checkout@v4

Setup Python

Install Python 3.11 with pip cache

actions/setup-python@v5

Install Dependencies

Install project + CI tool dependencies

requirements.txt ruff bandit pip-audit
↓
Stage 2: Code Quality & Linting

Ruff Linting

Static code analysis on app/, ui/, tests/, scripts/

ruff check
↓
Stage 3: Testing

Unit Tests

Test individual components: intent classifier, expense analysis, budget planning, anomaly detection, health assessment, goal planning, config

pytest tests/unit -v

Integration Tests

Test full agent pipeline end-to-end with mocked LLMs

pytest tests/integration -v

Security Tests

Test guardrails: input filtering & output validation against prompt injection, data leakage

pytest tests/security -v
↓
Stage 4: Security Scanning

LLMSecOps Policy Checks

Verify model registry, input guardrails, output validators against policy test cases

llmsecops_ci.py

Static Security Scan

Scan Python code for common vulnerabilities (SQL injection, hardcoded secrets, etc.)

bandit -r app scripts

Dependency Vulnerability Scan

Audit Python packages for known CVEs

pip-audit
↓
Stage 5: Container Build

Build Backend Image

Build Docker image for FastAPI backend service

Dockerfile.backend smartfin-backend:ci

Build Frontend Image

Build Docker image for Streamlit frontend

Dockerfile.frontend smartfin-frontend:ci

Job 3: deploy (needs: quality-security + llm-evaluations, push only)

Deployment to Production Server SSH + SCP + Docker Compose

Step 1: Prepare Remote Directory

SSH into server, create deployment directory at /opt/smartfin, clean old files

appleboy/ssh-action@v1.2.0

Step 2: Upload Source Code

SCP application source: app, ui, config, scripts, fixtures, requirements, docker files

appleboy/scp-action@v1

Step 3: Render .env & Restart

Write runtime environment variables, run docker compose up -d --build --remove-orphans

appleboy/ssh-action@v1.2.0 docker compose
